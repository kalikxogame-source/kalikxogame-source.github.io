Kalikxo Uploader

A personal desktop tool that publishes the owner's own original animated cartoon episodes to the owner's own TikTok account and YouTube channel, on a schedule, through the official TikTok Content Posting API and YouTube API Services.

Home Terms of Service Privacy Policy

What it does

  • Keeps a queue of the owner's finished episodes with titles, descriptions and hashtags.
  • At the scheduled time uploads the next episode to TikTok (Content Posting API) and to YouTube as a Short (YouTube Data API videos.insert).
  • Reads only the connected channel's name (channels.list?mine=true) to show which channel is linked.
  • Used only by its owner, with the owner's own accounts. No sign-up, no other users, no public service.
